# UD3.1 ejercicio 2 - menu que se queda fijo

Matias Nicolas Gonzalez, 1 ASIX

hice una pagina con banner, menu de 4 enlaces y 4 secciones con id, el menu usa position: sticky con top: 0, fondo y z-index, y el boton Subir es position: fixed abajo a la derecha

diferencia entre sticky y fixed: sticky esta en su sitio normal y se queda pegado arriba cuando llega al hacer scroll, fixed se saca del flujo y esta pegado a la ventana desde el principio, por eso el contenido de debajo sube y queda tapado por el menu, y hay que ponerle width: 100% porque se encoge
