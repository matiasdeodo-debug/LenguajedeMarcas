# Ejercicio 1: tres formas de incluir CSS

## ¿Cuál es la más cómoda para cambiar el color del título en 10 páginas?

la más cómoda al menos para mi, es la del archivo externo "estilos.css", todas las páginas
enlazan al mismo archivo, así que cambio el color en una sola línea y se
actualiza en las 10 páginas a la vez

## ¿Por qué se desaconseja la primera (inline)?

porque hay que repetir el estilo en cada elemento, así que el código se
llena de repeticiones y es muy difícil de mantener
