¿Qué es HTML?

HTML significa "lenguaje de marcas de hipertexto". No es un lenguaje de programación, sino un lenguaje que sirve para describir la estructura de una página web: qué parte es un título, cuál es un párrafo, cuál es una imagen, etc.

Los archivos HTML se escriben en un editor de texto como VS Code y se guardan con la extensión .html. Después, el navegador los lee e interpreta para mostrarnos la página ya terminada.

Etiquetas básicas

El HTML funciona con etiquetas, que normalmente se abren y se cierran, por ejemplo <p> y </p> para un párrafo. Lo que queda entre las dos etiquetas es el contenido que se muestra en la página.

Algunas de las más usadas son <h1> a <h6> para los títulos, <p> para los párrafos y <ul> con <li> para hacer listas. Con estas pocas ya se puede montar una página sencilla.

Imágenes

Para mostrar una imagen se usa la etiqueta <img>, que no necesita cierre. El atributo src indica dónde está la imagen y el atributo alt guarda un texto que la describe por si no carga.

Es importante guardar las imágenes del proyecto en una carpeta (por ejemplo img) y usar rutas relativas, para que la página siga funcionando aunque la copiemos a otro ordenador.

Enlaces

Los enlaces se crean con la etiqueta <a> y el atributo href, que dice a dónde lleva. El texto que ponemos dentro del enlace tiene que explicar a dónde va, y no ser algo vacío como "pincha aquí".

Con target="_blank" el enlace se abre en una pestaña nueva, y con href="#id" podemos saltar a otra parte de la misma página, que es justo lo que hace este índice.
